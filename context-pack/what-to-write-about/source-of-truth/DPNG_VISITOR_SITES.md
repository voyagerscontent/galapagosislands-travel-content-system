# DPNG VISITOR SITES — the official list (authoritative)

Source: Galápagos National Park Directorate (DPNG) / Fundación Charles Darwin visitor-site
dataset, mirrored in `source-of-truth/galapagos_master.xlsx` sheet `DPNG Site Activities`.
**210 sites across 23 islands.** Cite as `[source: DPNG Site Activities]`.

## Rules for using this list

1. **A site not on this list does not exist.** Never name a visitor site that is not here.
2. **Never invent an activity for a site.** If snorkelling is not listed for a site, do not
   say you can snorkel there. The activity columns are the permitted-use record.
3. `M` = marine site, `T` = terrestrial. Every site is a National Park visitor site: a
   GNPS-certified naturalist guide is required, and wildlife-distance rules apply.
4. Presence of a site says nothing about which vessels visit it — that is itinerary data.
5. This list is *sites*, not species. It does not license a wildlife claim: do not say an
   animal is at a site unless a fact file says so.
6. `quota` is the DPNG's published site quota (CUP) and `capacity` its visitor
   carrying-capacity metric (CAV). Quote them only as the Park's own operational figures.
